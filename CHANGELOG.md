# Changelog

## 0.4.0 — Unreleased

When no reference format is given, the prompt applies the recognised standard structure for
that kind of deliverable. Instructions rewritten as a compact checklist.

## 0.3.1 — Unreleased

Runs only when invoked by name (`disable-model-invocation`), so it costs nothing in other
sessions. One question round at most. Output is the prompt plus one `Open points` list.
Aims for the shortest prompt that fully works. Shorter description.

## 0.2.0 — Unreleased

The skill no longer reads files; the prompt tells the receiving agent what to inspect.
Shorter instructions: about 1.1k tokens when run, down from 2.5k.

## 0.1.0 — Unreleased

First release. One skill: `prompt-engineer`.
